# Lab 00: DHCP Configuration

## Objective
To configure DHCP in Cisco Packet Tracer and automatically assign IP addresses to client PCs.

## Tools Used
- Cisco Packet Tracer
- Router or DHCP Server
- Switch
- PCs
- Ethernet cables

## Network Topology
A DHCP server or DHCP-enabled router is connected to a switch. Client PCs obtain their IP configuration automatically.

## Configuration Tasks
1. Create the network topology.
2. Configure the network IP address.
3. Configure the DHCP pool.
4. Set the default gateway and subnet mask.
5. Enable DHCP on client PCs.
6. Verify the assigned IP addresses.

## Verification
- Check the assigned IP address on each PC.
- Verify the subnet mask and default gateway.
- Use the `ping` command to test connectivity.

## Expected Result
Client PCs receive valid IP configuration automatically from the DHCP service.
