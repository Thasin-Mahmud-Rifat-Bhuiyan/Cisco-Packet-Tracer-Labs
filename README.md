# Cisco Packet Tracer Labs

A practical collection of computer networking labs and projects completed using Cisco Packet Tracer.

## About This Repository

This repository documents my hands-on learning journey in computer networking, including network configuration, routing, switching, subnetting, troubleshooting, and network security.

## Topics Covered

- Basic Networking and LAN Setup
- IPv4 Addressing and Subnetting
- VLSM
- Router and Switch Configuration
- Static and Dynamic Routing
- VLAN and Trunking
- DHCP, DNS, and NAT
- Access Control Lists (ACL)
- Network Troubleshooting
- End-to-End Networking Projects

## Repository Structure

| Folder | Topics |
|---|---|
| 01-Basic-Networking | Basic LAN and connectivity |
| 02-IP-Addressing-Subnetting | IPv4, subnetting, VLSM |
| 03-Router-Configuration | Router CLI and interfaces |
| 04-Static-Dynamic-Routing | Routing protocols |
| 05-VLAN-and-Trunking | VLAN and inter-VLAN routing |
| 06-DHCP-DNS-NAT | Network services |
| 07-ACL-and-Network-Security | Access control and security |
| 08-WAN-and-Multi-Router | Multi-router topologies |
| 09-Troubleshooting | Connectivity and configuration issues |
| 10-Mini-Projects | Complete network scenarios |

## Tools Used

- Cisco Packet Tracer

Each lab may include:
