# RIP Routing Commands
## Lab: RIP Routing with 3 Routers, 3 Switches and 6 PCs

### 1. Router0 Configuration

```bash
enable
configure terminal

interface gigabitEthernet 0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit

interface serial 0/0/0
ip address 10.0.12.1 255.255.255.252
no shutdown
exit

router rip
version 2
no auto-summary
network 192.168.1.0
network 10.0.12.0
exit

end
write memory
```

### 4. Verification Commands

```bash
show ip interface brief
show ip protocols
show ip route
show running-config
```

### 5. Connectivity Testing

```bash
ping 192.168.1.2
ping 192.168.2.2
ping 192.168.3.2
```

### Note
- These commands use example IP addresses.
- Interface names may differ depending on the router model.
- If using serial DCE cables, configure a clock rate on the DCE side.
- Configure the IP addresses and default gateways on all PCs separately.
